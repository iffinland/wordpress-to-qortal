# Qortal Migration Studio 0.8.0 beta.1

<!-- qms-release-version: 0.8.0-beta.1 -->

The public prerelease tag is `v0.8.0-beta.1`. All three independently packaged
products are version `0.8.0-beta.1`:

- Qortal Migration Studio Desktop: `qortal-migration-studio_0.8.0-beta.1_amd64.deb`
- Migration Publisher: `qortal-migration-publisher-v0.8.0-beta.1.zip`
- Generic CMS: `qortal-migration-generic-cms-v0.8.0-beta.1.zip`

This is a versioning, packaging and documentation delivery. It deliberately
does not change the accepted application behavior, interfaces, visuals, data
contracts, migration source handling or QDN publication flow.

## Operational manuals

- [Qortal Migration Studio user manual](QORTAL-MIGRATION-STUDIO-USER-MANUAL.md)
- [Migration Publisher user manual](MIGRATION-PUBLISHER-USER-MANUAL.md)
- [Generic CMS user manual](GENERIC-CMS-USER-MANUAL.md)

The release is unsigned. `SHA256SUMS` covers the three downloadable product
assets. No QDN transaction or automatic publication is performed by downloading
or packaging these files.
