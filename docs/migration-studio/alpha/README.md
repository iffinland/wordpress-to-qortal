# Qortal Migration Studio 0.6.1 alpha documentation

This folder contains the user-facing documentation for the published 0.6.1
alpha of Qortal Migration Studio. The beginner path requires no development
tools: download the .deb and follow these guides. Downloading a Q-App ZIP is not
the same as publishing it to QDN; an owner must publish it with wallet approval.

| Document | Purpose |
| --- | --- |
| [RELEASE-NOTES.md](RELEASE-NOTES.md) | What this alpha contains, what is verified and what is not |
| [FIRST-RUN-GUIDE.md](FIRST-RUN-GUIDE.md) | Install, launch and create the first project |
| [MIGRATION-WALKTHROUGH.md](MIGRATION-WALKTHROUGH.md) | Import a WordPress site and hand a batch to Qortal Hub |
| [SYNC-AND-RECOVERY.md](SYNC-AND-RECOVERY.md) | Check for updates, handle conflicts, resume and clean up |
| [SUPPORTED-CONTENT.md](SUPPORTED-CONTENT.md) | What migrates and what is removed |
| [KNOWN-ISSUES.md](KNOWN-ISSUES.md) | Alpha limitations and open release gates |
| [FEEDBACK.md](FEEDBACK.md) | How to report a bug without leaking secrets |
| [VALIDATION.md](VALIDATION.md) | What was exercised on a real WordPress site, and what was not |

The canonical installation instructions are in
