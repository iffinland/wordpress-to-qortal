# Qortal Migration Studio 0.8.0 beta.2

<!-- qms-release-version: 0.8.0-beta.2 -->

Generic CMS is **0.8.0-beta.2**. Desktop and Migration Publisher remain **0.8.0-beta.1** (unchanged).

## Generic CMS fixes

- BUG-01: Android featured-image publication uses bytes captured at selection.
- BUG-02: CMS-native posts load without a QMS import manifest; duplicate homepage title removed.
- BUG-03: canonical/legacy native-index identity and public navigation during catalog errors.
- BUG-04: non-blocking global warning banners removed from public pages; Admin diagnostics preserved.
- Unused Adoption interface removed from Admin Overview. Existing local records and QDN content are untouched.
